CtrlV Portable Package
======================

This folder contains a portable CtrlV build produced with PyInstaller (onedir).

How to run
----------
1) Keep all files in this folder together.
2) Start CtrlV.exe.

Notes
-----
- Python runtime is bundled; no separate Python installation is required.
- User settings are stored in the user profile via QSettings.
- Removing this portable folder does not remove user settings.
