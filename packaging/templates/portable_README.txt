CtrlV Portable Build
====================

This folder contains a portable CtrlV build produced with PyInstaller (onedir).

How to run:
1) Open this folder.
2) Start CtrlV.exe.

Notes:
- Python is bundled; no separate Python install is required.
- Keep all runtime files in this folder together with CtrlV.exe.
- User settings are stored in the user profile (QSettings) and are not removed by uninstalling the installer.
